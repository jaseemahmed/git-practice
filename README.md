## About

A practice repo for learning Git and GitHub workflows. Building a website including chapters what I am learning and practicing professional git and github workflow to get more exposure to it.

# Usage

- Prerequisites
  - Git installed in your PC
  - A github account
  - VS Code (or a code editor of your choice)

- How to use

Getting started is quick and simple:

1. **Clone the repository**

   ```bash
   git clone [https://github.com/jaseemahmed/git-practice.git](https://github.com/jaseemahmed/git-practice.git)
   cd git-practice
   ```

2. **Run the application**
   - Directly: Locate `index.html` in the project folder and double click it to pen in the default browser.
   - Via Live Server: If using VS Code, open the folder, right-click index.html, and select "Open with Live Server".
